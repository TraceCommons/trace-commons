**Goal:** Run the same portable checks locally and on Dagger Cloud pushes, with observable cache reuse.

**Architecture:** Root dagger.json discovers a Python module in .dagger. Six independent annotated checks share tool-install layers and use per-architecture, per-lane Cargo caches. Existing required GitHub checks remain during migration.
