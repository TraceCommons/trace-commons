# Trace Commons 0.11.0: see your tools' model calls answered on your computer

*2026-09-07*

If you contribute coding sessions to Trace Commons, the app now has a
top-level screen called **Model calls** — on macOS, Windows and Linux —
where your coding tools' model calls can be answered from your own
computer, recorded there, and passed on to whoever you have set up to
answer them.

Think of it as a VPN for AI, with the same honesty a VPN deserves: your
calls go out through a point you control, which sees them and keeps the
record. It does not make the call invisible to whoever answers it — each
call is still passed on to the provider you configured. What changes is
that *you* now have the record, and the say over who answers.

## What is on the screen

**A list of the coding tools on your computer** — Claude Code and Codex
today — each showing one of three states: not connected, connected but
nothing has arrived yet, or answering. That last distinction is the whole
point. A settings file with the right value in it is not evidence that a
single call was ever answered; before this release you could turn the
feature on and have no way to tell whether anything was actually using
it. Now the screen tells you when a call from a tool genuinely reached
your computer and was answered there.

**Connecting a tool is one decision at a time, behind a preview.** Before
anything is written, the app shows you the exact change it would make to
that tool's own settings file, and writes nothing until you confirm. If
you already filled in a setting yourself, it is reported and left exactly
as you had it — never overwritten.

**The switch is in the tray (menu bar on macOS) and on a keyboard
shortcut.** Turning it off acts immediately — that only reduces what your
computer will answer. Turning it on opens the screen first, on purpose:
while it is on, anything else running on your computer can send calls
through it, charged to the accounts you have set up. That is a decision
to make with the consequence in front of you, not from a menu.

## The limits, plainly

- **Two tools, not four.** Gemini is not supported: the mechanism can
  write one of two API shapes, and neither is Gemini's. Cline keeps no
  settings file we can find. We would rather say this than imply more is
  coming.
- The feature does nothing until you connect a tool. Turning the switch
  on, by itself, changes where no tool sends its calls.
- This is not a privacy feature. It moves where your calls are answered
  from and keeps the record on your computer; the destination still sees
  what you send it.

## Along the way

Building this on IronWire, the local component that does the answering,
we found and fixed seven defects in it — all merged upstream. Two worth
naming: connecting a tool could move a setting you had already chosen,
and a preview of additions could commit a removal. Those fixes reach you
whether or not you use this screen.

## Getting it

The desktop app updates itself. The CLI is on Homebrew.
