# Near.ai v0.17.0

This release adds managed coding sessions you can start from the app, and it keeps uploads going through short outages. The macOS app also has a new look.

- Find your local OpenCode traces, and start managed sessions in OpenCode (#1417, #1418).
- Choose the terminal a managed session opens in (#1423).
- Bring a managed session to the front, stop it, or start it again (#1426).
- See which coding tools are installed, with help to recover a failed install (#1419).
- Read why the app asks for a folder before your first managed launch (#1422).
- Cancel a NEAR AI sign-in that is in progress (#1425).
- Uploads that fail while the service is unavailable are retried automatically (#1410).
- A mode you set for a project from the command line now applies, whatever the letter case of its path (#1409).
- The macOS app has a redesigned light theme, Home tiles that open their tabs, and a simpler Join step (#1387).

Available on macOS, Windows and Linux. Changes include #1387, #1409, #1410, #1417, #1418, #1419, #1422, #1423, #1425 and #1426.
