# Trace Commons v0.12.4

Signing in to NEAR AI through the browser reported success as soon as the callback arrived, before the inference key was created and stored. If that setup then failed, an older stored key could hide the failure, and the app looked signed in when it was not.

- Browser sign-in now waits for credential setup to finish before reporting success, and returns a definite error when it does not.
- A failed retry stays visible rather than being masked by a credential stored earlier. Existing credentials are preserved.

Also in this release, carried over from v0.12.3: reopening the app while a watcher is already running attaches to that watcher instead of reporting that the watcher is not running.
