# Near.ai v0.19.0

Sessions that run on your NEAR AI account now start on a model chosen for each tool, and you can switch models from inside the tool.

- Claude Code starts on NEAR AI's newest Sonnet and Codex on its newest GPT model, instead of whichever model came first in NEAR AI's list (#1463).
- The model picker in Claude Code, Codex and OpenCode lists NEAR AI's chat models, and the model you pick is the one that answers (#1466).
- Claude Code shows a status line for these sessions, naming the model that answered (#1466).
- Connecting Claude Code no longer leaves it with a blank status line (#1462).

Available on macOS, Windows and Linux. Changes include #1462, #1463 and #1466.
