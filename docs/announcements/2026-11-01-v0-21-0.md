# Near.ai v0.21.0

Private AI sessions now start on a NEAR AI private model, you can choose models by how private they are, and you can resume a session you ended. Sign-in is NEAR AI login only, and the daily upload limit is gone.

## Choose a Private AI model

- On macOS, the model picker groups NEAR AI's models by privacy, most private first: NEAR AI private models, which run in NEAR AI's own TEEs (secure hardware enclaves); External private models, which run in another provider's TEE; and Incognito models, which run on the vendor's servers and are reached through NEAR AI (#1761, #1789).
- Star a model to make it a favorite. Favorites stay at the top of the picker and show their privacy group (#1754, #1790, #1797).
- Claude Code and OpenCode start on a NEAR AI private model when NEAR AI lists one. Codex keeps its current default (#1797).
- A Background model picker sets the model Claude Code and OpenCode use for background work, such as titles and quick checks (#1798).
- The other models a session uses, for background work and helper agents, are never less private than the model you chose. A project's Claude Code settings cannot move a NEAR AI session onto a less private model (#1798, #1803).
- Each tool now knows each model's context window, so long sessions compact before NEAR AI refuses a request as too long. Models with large windows, such as GLM 5.3, take longer requests (#1774, #1788).

## Resume a session

- An ended session in Manage sessions offers Resume, which continues the same conversation, and Copy resume command, which gives a line to resume it from any terminal. This works for Claude Code, Codex and OpenCode. From the command line, run `near-ai sessions resume <id>` (#1799).
- A resumed session keeps the original session's trace collection setting. A trace is a record of a session with an AI tool (#1799).
- On macOS, you can start a session without choosing a folder; it starts in your home folder. The first launch asks which terminal to use, and kitty, WezTerm and Alacritty are now offered (#1715, #1766).

## Fewer stuck sessions

- Claude Code sessions save their transcript when started from inside another Claude Code session, and tool calls no longer fail with "Invalid tool parameters" (#1763).
- When the Private AI proxy hits an internal error, the tool gets an error it can read instead of a dropped connection (#1788).
- Conversations with some accented letters or symbols no longer make every request fail (#1796).
- Failed requests are no longer listed as calls on the Private AI screens (#1787).
- If your NEAR AI balance cannot pay for a session's first calls, the app says so before it starts the session (#1763, #1768).

## Sign in with NEAR AI

- Passkeys are removed. Sign in with your NEAR AI login. Login links, NEAR wallet login and device sign-in work as before (#1784).
- Your account session renews in the background while you use the app. On macOS, when it cannot, Sign in again is a button (#1603, #1606, #1609, #1612).

## Upload more

- The daily upload limit is removed from every app (#1783, #1801).
- The app reads sessions up to 512 MiB, and the commons accepts traces up to 256 MiB (#1742, #1746).
- Codex's compressed sessions are offered for contribution (#1735).
- When the commons is busy or restarting, apps wait a varied time before they retry, so uploads resume more smoothly (#1805).

## Also on macOS

- Insights has three tabs: Overview, Breakdown and Benchmarks. It shows NEAR AI spend by model and the goals you set with `/goal` in Claude Code and Codex (#1718, #1721, #1731).
- The Traces tab has Automatic switches, for every folder at once and for each folder (#1757, #1760).
- You can drag the Traces, Private AI and Insights tabs into any order (#1756).
- The Traces map shows your account's other devices and what each has contributed. You can link a server to your account with a one-time code (#1668, #1669, #1675, #1677).
- Install Command-Line Tool puts the `near-ai` command on your PATH, and the menu bar menu has Check for Updates (#1716, #1730).
- Quitting the app no longer hangs (#1752).

## Current limits

- The model picker, the Background model picker, the Resume buttons and the device map are on macOS only. On Windows and Linux, resume a session from the command line.
- If you signed in with a passkey, sign in again with your NEAR AI login.
- The commons still limits how many traces an account can send each hour and each week. When you reach a limit, uploads wait and retry on their own.
