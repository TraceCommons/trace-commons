# Trace Commons v0.12.6

Trace cards for Codex and Claude Code now show the first task request after known injected setup blocks. Previously, cards could show AGENTS.md instructions, plugin lists, or editor context, making sessions hard to tell apart.

- Skips known setup blocks when selecting the card preview, including when the request follows a block in the same message.
- Shows “No task description found.” when no request is available.
- Preserves the full transcript and applies the same redaction before selecting preview text.

Windows settings saves also retry briefly when another reader or file scanner temporarily blocks replacement of the configuration file. Persistent failures still return an error and preserve the previous file.

This is a maintenance release based on v0.12.5.
