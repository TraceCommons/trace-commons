# Near.ai v0.21.1

A project can no longer move a NEAR AI session onto a less private model, Insights asks for Keychain access far less, and uploads keep retrying through a long outage.

- On a NEAR AI session, a project's Claude Code settings, commands, skills and routines can't choose a model, and neither can folders you add with `--add-dir`. Such a project is refused with "This project's Claude Code settings, agents, commands or skills choose a model. NEAR AI sessions use the session's models." (#1810, #1811).
- A project with Claude Code workflows starts as normal. A notice says a workflow step can choose its own model. It shows in the macOS session sheet and in the terminal (#1811).
- When the commons can't be reached, uploads keep retrying for at least six hours (#1809).
- Email addresses with accented letters are now fully hidden. Long sessions leave room for the model's answer (#1812).
- On macOS, Insights asks for Keychain access far less often. A Claude Code token renewal no longer triggers a new prompt (#1815, #1823).
- The daily digest shows credit that is final as earned, and credit still being scored as pending (#1816, #1822).
- On macOS, each Private AI session row shows one action, with the rest in the ⋮ menu. Long model names are no longer cut off (#1819).
- On macOS, the model picker and the session rows show model names. The model list is kept as a saved copy, so the picker rarely waits for NEAR AI (#1824, #1825).
- On Windows, a backslash in `--add-dir` paths is read as written. On a NEAR AI session, a `--add-dir` path that gives only a drive and a folder, such as `C:shared`, is refused as invalid options (#1814, #1817, #1821).
- If the app can't load the Home card, it shows the NEAR AI Red card (#1808).

Available on macOS, Windows and Linux. Changes include #1808, #1809, #1810, #1811, #1812, #1814, #1815, #1816, #1817, #1819, #1821, #1822, #1823, #1824 and #1825.
