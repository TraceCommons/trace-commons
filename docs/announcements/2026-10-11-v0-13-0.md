# Near.ai v0.13.0

The contributor app is now called Near.ai. Trace Commons remains the name of the commons your traces are contributed to. On macOS the app installs as `Near.ai.app` from `Near.ai-0.13.0.dmg`; an existing install keeps working and updates in place, so it may still be named `TraceCommons.app` in Finder.

This is the first release from `main` since v0.12.2, and the macOS app changes the most:

- A redesigned macOS app with a menu-bar panel, a new first run, and passkey sign-in through near.ai, including a second Mac joining the same account.
- Insights on macOS: token use by day, patterns in tool calls, and a per-trace breakdown, all computed on this Mac.
- Suggestions and missions on macOS, with the switch that controls them in Settings.
- A Private AI section in Settings, including whether to count Private AI tokens.

In every app:

- Folder modes have one set of names: Ask me, Automatic and Never.
- Contribution scopes must be chosen before anything is sent, and the review shows what leaves the device.
- Traces waiting on a busy privacy check show as waiting rather than failed.
- Uploads the server rate-limits stay queued and are retried at a steady pace.

Changes include #1258, #1287, #1290, #1303, #1341, #1342, #1357 and #1360.
