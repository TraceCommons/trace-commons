# Near.ai v0.16.1

This release fixes a crash on macOS. With the edge rail turned on, moving the pointer in and out of the screen edge could close the app. The rail now sizes its window only once SwiftUI has finished laying it out.

The pending credit figure on macOS no longer has the settlement and not-currency notes beside it.

Available on macOS, Windows and Linux. Changes include #1401 and #1402.
