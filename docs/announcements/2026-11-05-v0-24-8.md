# Near.ai v0.24.8

For macOS.

- Automatically accept owner-signed privacy witness endpoint and attestation updates, so compatible witness migrations can reach this client without another app release (#2006).
- Move tabs with a direct drag; movable tabs lift on hover (#1995).
- Setup connects tools first and asks about data uses last. A connected tool is required to finish; Use Private AI only is removed. Existing completed setups are unchanged (#1999).
- You can skip choosing data uses, folder rules and past traces. Skipping keeps sharing on Ask each time and still records the always-on data use. Train coding models stays off, so skipped setup earns no credit (#1999).
- While Train coding models is off, Home says you will not earn credit and links to Settings, including for existing signed-in accounts. Earning credit also requires a connected tool and eligible contributions (#2002).
- First run always uses dark appearance. Uses removes Allow all and Only required, and moves Customize from Tools to Uses (#1999).

## Known limitations

- After Skip, the final button still says Start sharing, and the Uses graphic can show traces flowing with no optional use selected. Ask each time still requires approval before an upload (#1999).
- Skip and the final setup step do not explicitly say that skipping earns no credit. The training toggle marks it as required for credit; the Home reminder appears after setup (#1999, #2002).
