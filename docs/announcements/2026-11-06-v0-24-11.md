# Near AI Gateway v0.24.11

For macOS and the contributor CLI. Windows and Linux desktop apps remain on their existing releases.

- The app is now called Near AI Gateway in Finder, Launchpad, the app switcher, the menu bar and its own text. Installed copies take the new name with this update; the file in Applications is still `Near.ai.app`, and the `near-ai` command keeps its name (#2019).
- Sign-in with the NEAR Mobile wallet works again. Its connector changed upstream and the app's integrity check refused it; the new version was reviewed and pinned (#2014).
- Managed Codex sessions talk to NEAR AI's Responses API directly, keep Codex's own tool settings, and can use every model NEAR AI lists for Codex. Hosted web search is available only on OpenAI models (#2016).
- Account, organization, usage and credit requests go to `cloud-platform.near.ai`, where NEAR AI moved them. Inference is unchanged (#2018).
