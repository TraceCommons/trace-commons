# Near.ai v0.24.0

You can now finish setup with Private AI alone, and start over or switch accounts from more places in the app. This release is for macOS.

## Setup

- First run can finish with Private AI only. You do not need to share traces to finish setup (#1922).
- The last step no longer shows an amount. It says whether we found traces that can earn credit (#1921, #1926).
- A failed sign-in says "Sign-in didn't finish. Try again." (#1922).

## Account

- Set up again is now in the Connection section of Settings, whenever you want a clean sign-in (#1912).
- Use a different account is now in the Private AI section as well as the account section (#1912).
- If a switch of account fails, the app says why (#1912).
- After you sign out, the Account card says "Not signed in" (#1924).

## Settings

- Settings are grouped into Account, Payouts, Sign out, Insights and Advanced (#1919).
- Settings text is shorter, and no longer names controls that are not there (#1918, #1929).

## Traces

- Start again replaces the ended row it came from (#1915).
- Resume is offered from Traces while sharing is paused (#1912).

Available on macOS. Changes include #1912, #1915, #1918, #1919, #1921, #1922, #1924, #1926 and #1929.
