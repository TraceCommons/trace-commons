# Near.ai v0.24.9

For macOS and the contributor CLI. Windows and Linux desktop apps remain on their existing releases.

- Submit starts the secure privacy check for ordinary traces you have not previewed (#2011).
- On startup, older holds caused only by scrubbing matching nothing are cleared so those traces can go through a fresh privacy check. Traces flagged as uncertain or trimmed still need individual review (#2011).
- On macOS, submission results show scrub counts only when a scrub result is available. A pending privacy check or a group held entirely for individual review no longer says “Scrubbing matched nothing” (#2011).

The existing requirements for admission evidence, token bundles, corrections and reviewed previews remain in place. This release keeps the current Phala privacy-check server.
