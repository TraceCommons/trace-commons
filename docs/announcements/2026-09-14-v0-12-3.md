# Trace Commons v0.12.3

Reopening the app while a watcher was already running reported "The watcher isn't running." The watcher was running; the app had no way to reach one it had not started itself, so it described a working watcher as a stopped one.

- The app now attaches to a watcher already running for the same folder, whether that is a copy of the app that has not fully exited or a `trace-commons-contributor daemon` started from a terminal.
- A window driving a watcher it did not start says so, and says what it cannot do from there: stop that watcher, or open a trace's full text. Both were previously silent dead ends.
- Every other refusal the watcher can report at startup now has its own sentence instead of a shared one.

A window attached to another copy's watcher can still review and approve. Quit the other copy and reopen this one for the whole app.
