# Trace Commons v0.12.5

Signing in to NEAR AI Cloud completed and then stopped working. The app stored the credential and created the inference key, reported success, and minutes later the account and balance screens said the session had expired. Signing in again produced the same thing, because each new session was refused for the same reason as the last.

NEAR AI ties a retained session to the browser that created it, and checks that on every refresh. Trace Commons refreshed as itself rather than as the browser, so the service could not recognise the session it had just issued.

- The retained session now records the agent that created it and presents it when refreshing, so a sign-in keeps working after the browser closes.
- A sign-in that cannot record one is refused while the browser page is still open, instead of storing a session that could never be refreshed.

Contributing and private inference were never affected: the inference key is authenticated differently and kept working throughout. Only the account and balance screens were.

Sessions stored by an earlier version cannot be repaired, because nothing recorded what the service needs. Signing in once on this version replaces them.
