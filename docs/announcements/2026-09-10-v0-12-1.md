# Trace Commons v0.12.1

Route AI requests through NEAR AI with a simpler Private AI page. If you are signed out, sign-in is now the first action you see. Controls and status messages are clearer across macOS, Windows and Linux.

- Shorter, consistent messages explain contribution status, approvals and errors.
- Private AI keys, NEAR AI refresh tokens, Commons sessions and device keys now use macOS Keychain, Windows Credential Manager or Linux Secret Service.
- Wallet signup checks server readiness and explains mismatched signup details before signing a device proof.

Existing credentials migrate when they are next read, preserving your device identity. Keep your OS credential store available and unlocked. After migration, copying the contributor folder alone does not back up your credentials, and older versions cannot read the migrated credentials. See the [credential recovery guide](../operator/commons-credential-storage.md).
