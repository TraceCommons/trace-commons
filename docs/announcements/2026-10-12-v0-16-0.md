# Near.ai v0.16.0

You no longer need an invite to contribute from the command line. Run `trace-commons-contributor login` and it opens near.ai in your browser. Sign in with NEAR AI, and this device is enrolled. If you are already signed in to NEAR AI in the app, it skips the browser.

- Invites still work: `login --invite <link>`, or set `TRACE_COMMONS_INVITE`.
- `submit` on a device that isn't enrolled signs you in first, then carries on. Without a terminal, or with `--json`, it tells you how to enroll instead.
- `login` used to print this device's key id. That is now `login --key-id`, so update any script that relied on it.

On macOS, the contribution rule is now one sentence per route, and an armed folder in Traces shows a one-sentence summary with the details behind an info button.

Available on macOS, Windows and Linux. Changes include #1393, #1397 and #1398.
